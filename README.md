# javascript-lotto-precourse

## 📋 요구사항 명세서

- 프로그램 실행 시 `"구입금액을 입력해 주세요."` 메세지를 출력한다.
- 사용자로부터 `로또 구입 금액`을 입력받는다. `단위는 1,000원`이며 나누어 떨어지지 않는 경우 예외처리한다.
- 1,000원 단위로 자른 개수인 n에 대해 `"n개를 구매했습니다."` 메세지를 출력한다.
- 이후 `"당첨 번호를 입력해 주세요."` 메세지를 출력한 후, 사용자로부터 `당첨 번호`를 입력받는다. 당첨 번호는 `쉼표(,)`를 기준으로 구분한다.
- 이후 `"보너스 번호를 입력해 주세요."` 메세지를 출력한 후, 사용자로부터 `보너스 번호`를 입력받는다.
- 입력이 완료되면 `"당첨통계"` 메세지와 `"---"`를 출력한 후, `당첨 내역`을 출력한다.
- 당첨 내역은 3개~6개 일치 항목을 순서대로 다음 형식에 맞춰 출력한다. (n은 실제 당첨된 개수)
  - 3개 일치 (5,000원) - n개
  - 4개 일치 (50,000원) - n개
  - 5개 일치 (1,500,000원) - n개
  - 5개 일치, 보너스 볼 일치 (30,000,000원) - n개
  - 6개 일치 (2,000,000,000원) - n개
  - `"총 수익률은 [수익률]%입니다."` 형식으로 수익률을 출력한다.
- 수익률은 `소수점 둘째 자리`에서 반올림한다. (ex. 100.0%, 51.5%, 1,000,000.0%)
- 예외 상황 시 `[ERROR]`로 시작하는 에러 문구를 출력한다.

## ⚙️ 구현할 기능 목록

### Lotto.js

#### 1️⃣ 로또 번호 유효성 검사 기능

- [x] 로또 번호 개수가 6개가 아니면 오류를 발생시킨다.
- [x] 로또 번호가 정수가 아닐 때 오류를 발생시킨다.
- [x] 로또 번호가 중복될 시 오류를 발생시킨다.
- [x] 로또 번호는 1~45 사이의 숫자가 아닐 시 오류를 발생시킨다.

#### 2️⃣ 로또 번호 및 문자열 반환 기능

- [x] 로또 번호 배열을 반환한다.
- [x] 로또 번호를 정해진 형태의 문자열로 반환한다.

### LottoGame.js

#### 1️⃣ 로또 배열 생성 기능

- [x] 로또 구입 금액에 따른 로또 개수만큼 로또 객체을 만들어 배열로 반환한다.

#### 2️⃣ 로또 객체 생성 기능

- [x] 하나의 로또 객체를 만들어 반환한다.

#### 3️⃣ 통계 생성 기능

- [x] 로또 배열의 모든 로또에 대해 등수를 계산해서 통계 객체를 반환한다.

#### 4️⃣ 로또 배열 반환 기능

- [x] 로또 배열을 반환한다.

### WinningLotto.js

#### 1️⃣ 당첨 번호와 보너스 번호 유효성 검사

- [x] 당첨 번호와 보너스 번호가 중복될 시 오류를 발생시킨다.

#### 2️⃣ 등수 확인 기능

- [x] 당첨 로또와 비교하여 등수를 계산해서 반환한다.

#### 3️⃣ 등수 추출 기능

- [x] 겹치는 번호 수와 보너스 여부를 받아 등수를 반환한다.

### Statistics.js

#### 1️⃣ 총 상금 계산 기능

- [x] 등수에 따라 총 상금을 계산해서 반환한다.

#### 2️⃣ 수익률 계산 기능

- [x] 사용한 금액과 총 상금을 비율로 계산하여 수익률을 반환한다.

#### 3️⃣ 전체 등수 반환 기능

- [x] 전체 등수를 반환한다.

#### 1️⃣ 로또 구입 금액 입력 기능

- [x] 사용자로부터 로또 구입 금액을 입력 받는다.

#### 2️⃣ 당첨 번호 입력 기능

#### 3️⃣ 보너스 번호 입력 기능

#### 1️⃣ 로또 배열 출력 기능

- [x] 로또 배열에 대해 모든 로또를 문자열로 출력한다.

#### 2️⃣ 당첨 통계 출력 기능

- [x] 전체 등수를 정해진 형태로 출력한다.
- [x] 수익률을 출력한다.

### 🚫 예외 처리 기능

- [x] 로또 번호는 모두 정수여야 한다.
- [x] 로또 번호는 중복될 수 없다.
- [x] 로또 번호는 1~45 사이의 숫자여야 한다.

- [x] 보너스 번호는 모두 정수여야 한다.
- [x] 보너스 번호는 1~45 사이의 숫자여야 한다.
- [x] 보너스 번호는 당첨 번호와 중복될 수 없다.
